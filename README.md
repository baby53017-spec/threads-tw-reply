# 脆留言產生器 Threads TW Reply（Claude Skill）

讓 AI 幫你寫 Threads（脆）留言，聽起來像真的台灣人在講話，不是 AI 腔。

- 一定會接住原文的具體細節，不寫萬用留言
- 口語、短句、不客套
- 長短有變化，結尾自動丟問題，讓對方想回你

## 怎麼用

1. 下載這個資料夾（右上角 Code → Download ZIP）
2. 到 Claude 的「設定 → 功能 → Skills」上傳這個 ZIP
3. 對 Claude 說：「幫我回這篇脆」，然後貼上原文
