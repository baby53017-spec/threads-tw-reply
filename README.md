# 脆留言王｜Threads 台灣口語留言 Skill

> 市面上的脆 Skill 都在教你發文，這個教你**留言**。
> 留言互動是脆上漲粉最快的方法，但大部分人的留言不是太客套，就是一看就是 AI。

貼上別人的貼文，Claude 就會給你 3 則**像真人、會被按讚、會讓人點進你主頁**的台灣口語留言。

## 各行各業都能用

美業、餐飲、房仲、保險、設計師、水電、律師、教練、工程師、一般上班族……
只要跟 Claude 說「我是做○○的」，它就會用你這行才知道的小知識幫你留言。沒說行業，就用一般人的口吻。

**同一篇「搬新家樓上很吵、牆壁有霉味」：**
- 房仲：我帶看都會提醒客人晚上再來聽一次，白天根本聽不出來。你當初是白天看的嗎？
- 水電：霉味如果是牆壁裡面滲水，除濕機開再久也沒用欸。你那面牆是靠浴室嗎？
- 室內設計：樓板噪音其實可以在天花板加一層隔音，不用整個重做。你是租的還是買的？

跟你的行業沒交集的貼文，它不會硬扯，會改用一般聊天的方式留言，才不會像廣告。

---

## 四種模式

- **海巡留言**：去熱門貼文底下留言，被看到、被按讚
- **導流留言**：店家、接案者用專業留言讓人好奇點進主頁，不像廣告
- **回粉絲**：自己貼文底下的留言，回得自然、讓對話繼續
- **救冷場**：貼文沒人理，自己補一則帶話題

## 為什麼不一樣

- 每則都會接住原文的具體細節，**不寫萬用留言**
- 6 種留言打法（接細節、我也是、補一刀、反問、接梗、溫和唱反調），三則不重複
- 內建台灣脆用語，禁用「感謝分享、受益良多」這類 AI 腔
- 導流模式不放連結、不說「歡迎私訊」，讓人好奇你是誰，而不是知道你在賣東西
- 每次都會推薦最適合的一則
